# Quincestone repository instructions

- Treat `quinceweb/quincestone` as the only canonical repository.
- Build at the repository root; never create a nested application.
- Use the name **Quincestone**, never “Quincestone Systems.”
- Preserve the positioning: edge intelligence infrastructure for modern business websites and applications.
- Keep public demonstrations fictional and deterministic. Never expose real submissions in demo operations.
- Do not expose Supabase service-role credentials in browser code.
- Do not claim an external integration works until it has been verified.
- Run `npm run check` before publishing changes.
